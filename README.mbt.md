# gaato/dave

`gaato/dave`, the MoonBit bindings for Discord's
[`libdave`](https://github.com/discord/libdave), has moved to
https://github.com/gaato/discord.mbt/tree/main/dave and is released from
there.

The module name is unchanged, so this still installs it:

```sh
moon add gaato/dave
```

This repository is archived. Please open issues and pull requests in
[gaato/discord.mbt](https://github.com/gaato/discord.mbt).
